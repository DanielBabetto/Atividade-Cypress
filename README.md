# Objetivo
Automatizar o teste de componentes básicos de um formulário utilizando Cypress e GitHub Actions.

# Teste Realizado
O teste acessa a página Actions do Cypress Example, preenche o campo de e-mail (`.action-email`), valida o seu valor e, em seguida, seleciona uma caixa de seleção (checkbox) confirmando se ela está marcada.

# Execução
Para executar os testes é necessário:
```bash
npm test
